PX Publishing Manager

Private application · Public information

A considered workflow.
From draft to approved post.

X Publishing Manager is a private application being developed to help its owner review, approve, schedule, and measure posts on their own X account.

In development · Live publishing disabled

Designed around
owner approval

  1. Review the complete post

    Bring prepared drafts and media into a private workspace for a complete preview before approval.

  2. Approve, then schedule

    The intended workflow requires explicit owner approval before a post can be scheduled and published through X’s official API.

  3. Track and learn

    Record published-post links and collect available performance metrics to support the owner’s content analysis.

Private by purpose

The application is intended solely for its owner’s account. It is not a public posting service, and this information page does not offer account registration or access to the application.

The application initially runs locally on the owner’s computer. X authorization is handled separately through OAuth; this public site does not receive OAuth callbacks, credentials, or access tokens.

About this website

This static information page contains no publishing application code, private content queue, account records, API credentials, or Google Sheets data. It has no forms, embedded third-party media, analytics scripts, or advertising.

GitHub Pages provides website hosting and may process standard request information under GitHub’s Privacy Statement.

Current development status

OAuth configuration and local testing are underway. Publishing and scheduling are not enabled. The workflow described above represents the application’s intended capabilities.
